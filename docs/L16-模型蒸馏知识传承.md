## 正文

### 1. 知识蒸馏的动机

经过完整的训练流程（预训练 → SFT → RLHF），minimind-3 已经相当强大，但有个问题：**64M 的参数还是太多了**。

- 推理速度慢
- 显存占用多
- 不能部署到手机/嵌入式设备

**知识蒸馏**的想法：用一个大模型（Teacher）的"经验"去教一个小模型（Student），让小模型在 1/10 的参数下达到 70% 的性能。

### 2. 软标签 vs 硬标签

标准的有监督学习用的是"硬标签"（one-hot）：

```
输入：什么是大语言模型？
硬标签：[0, 0, 1, 0, 0, ...]（第 3 个 token 的概率是 100%）
```

但硬标签组织不足——它说 token_3 是对的，但没说 token_5 为什么多少有点对劲。

**软标签**是模型输出的完整概率分布：

```
Teacher 的输出：
[0.01, 0.02, 0.94】(硬标签), 0.01, 0.005, ...]
              ↑ 高温被"拉平"后
[0.1, 0.15, 0.6, 0.1, 0.05, ...]（软标签，温度=5）
```

关键是 **温度参数**（Temperature）。高温会把 softmax 的输出变得更"平顺"，这样不仅教会 Student "正确答案"，还教了"哪些错误答案相对不那么错"。

$$P(\text{token}_i) \propto \exp\left(\frac{z_i}{T}\right)$$

其中 $T$ 是温度：
- $T=1$：标准 softmax，输出分布尖锐
- $T \to \infty$：接近均匀分布，所有 token 概率接近

### 3. 蒸馏损失函数

知识蒸馏的损失是两部分的组合：

$$L = \alpha \cdot L_{\text{ce}} + (1-\alpha) \cdot L_{\text{kd}}$$

其中：
- $L_{\text{ce}}$：Student 在真实标签上的交叉熵（保持任务相关性）
- $L_{\text{kd}}$：Student 的软标签与 Teacher 的软标签的 KL 散度（学习知识）

$$L_{\text{kd}} = \text{KL}(P_{\text{teacher}} \| P_{\text{student}}) = \sum_i P_{\text{teacher}}(i) \log \frac{P_{\text{teacher}}(i)}{P_{\text{student}}(i)}$$

### 4. 实现蒸馏

```python
def distillation_loss(student_logits, teacher_logits, labels, temperature=5.0, alpha=0.5):
    """
    student_logits: 学生模型的原生输出 [B, T, vocab_size]
    teacher_logits: 教师模型的输出（冻结） [B, T, vocab_size]
    labels: 真实标签 [B, T]
    temperature: 软标签的温度
    alpha: 权重，0 表示只用软标签，1 表示只用硬标签
    """
    
    # ① 硬标签损失（学生在真实标签上的表现）
    ce_loss = cross_entropy(
        student_logits.view(-1, vocab_size),
        labels.view(-1)
    )
    
    # ② 软标签损失（学生模仿教师）
    # 将 logits 除以温度，使其更平顺
    student_probs = torch.nn.functional.log_softmax(student_logits / temperature, dim=-1)
    teacher_probs = torch.nn.functional.softmax(teacher_logits / temperature, dim=-1)
    
    # KL 散度
    kd_loss = torch.nn.functional.kl_div(
        student_probs.view(-1, vocab_size),
        teacher_probs.view(-1, vocab_size),
        reduction='mean'
    ) * (temperature ** 2)  # 缩放因子，保证量级一致
    
    # ③ 综合损失
    total_loss = alpha * ce_loss + (1 - alpha) * kd_loss
    return total_loss

def train_distillation(teacher_model, student_model, train_loader, 
                      optimizer, num_epochs=5, temperature=5.0, alpha=0.5):
    """
    teacher_model: 教师模型（冻结，不更新）
    student_model: 学生模型（需要训练）
    """
    
    teacher_model.eval()
    student_model.train()
    
    for epoch in range(num_epochs):
        for batch in train_loader:
            input_ids = batch['input_ids']
            labels = batch['labels']
            
            # 教师推理（不计图）
            with torch.no_grad():
                teacher_outputs = teacher_model(input_ids)
                teacher_logits = teacher_outputs.logits
            
            # 学生推理
            student_outputs = student_model(input_ids)
            student_logits = student_outputs.logits
            
            # 计算蒸馏损失
            loss = distillation_loss(
                student_logits, teacher_logits, labels,
                temperature=temperature, alpha=alpha
            )
            
            loss.backward()
            torch.nn.utils.clip_grad_norm_(student_model.parameters(), 1.0)
            optimizer.step()
            optimizer.zero_grad()
```

### 5. 蒸馏的实践技巧

| 技巧 | 作用 |
|------|------|
| 温度 5-20 | 太低教不了东西，太高没区别 |
| alpha=0.3-0.5 | 软标签权重应大于硬标签，避免学过头 |
| 保留一些预训练数据 | student 容易遗忘，混入预训练数据缓冲 |
| 教师是 fine-tuned 模型 | 教师本身要好，否则负迁移 |
| Checkpointing | 量化后的教师权重体积小，易于保存 |

## 💡 本节小结

| 概念 | 一句话总结 |
|------|-----------|
| 知识蒸馏 | 用大模型教小模型，用软标签而非硬标签 |
| 软标签 | 模型的完整概率分布，包含"次优"答案的排序信息 |
| 温度 | 控制概率分布的"平顺程度"，高温更平顺 |
| KL 散度 | 衡量两个概率分布的差异 |
| 混合损失 | 真实标签 + 软标签加权，避免单纯模仿 |
