# 07 - 训练技巧与优化器面试 50 题

## 1-10：优化器基础

1. Adam 的核心思想是什么？
- 答：一阶矩估计（动量）+ 二阶矩估计（自适应学习率）。

2. AdamW 为什么比 Adam 更适合 LLM？
- 答：解耦权重衰减，正则化更干净，泛化通常更好。

3. SGD 为什么较少用于大语言模型预训练？
- 答：收敛慢、对学习率更敏感，在稀疏/高噪声梯度场景不如 Adam 系。

4. 学习率 warmup 的作用？
- 答：初期避免大步更新导致发散，稳定进入有效训练区间。

5. Cosine decay 的优点？
- 答：后期平滑下降，有助于收敛质量。

6. OneCycle 适合 LLM 吗？
- 答：可用但不主流，LLM 多用 warmup + cosine。

7. beta1、beta2 分别影响什么？
- 答：beta1 控制动量平滑，beta2 控制方差估计平滑。

8. epsilon 参数的作用？
- 答：防止分母为零，提升数值稳定性。

9. 权重衰减该加在哪些参数上？
- 答：通常加在线性层权重，不加 bias 和 norm 参数。

10. 如何判断学习率太大？
- 答：loss 振荡或发散、梯度范数异常增大。

## 11-20：稳定训练

11. 梯度爆炸常见信号？
- 答：loss 变 NaN/Inf，grad norm 飙升。

12. 梯度裁剪（clip grad norm）怎么用？
- 答：反向后、优化前执行，限制全局梯度范数上限。

13. 梯度消失怎么排查？
- 答：看 grad norm 长期接近 0，检查激活、初始化、归一化位置。

14. 混合精度训练为什么要 loss scaling？
- 答：避免 FP16 下小梯度下溢。

15. BF16 与 FP16 如何选？
- 答：BF16 动态范围更大，通常更稳，现代硬件优先 BF16。

16. 激活 checkpointing 的本质？
- 答：以计算换显存，反向时重算部分前向。

17. 为什么设置随机种子后结果仍有波动？
- 答：并行非确定性 kernel、数据顺序、硬件差异。

18. LayerNorm/RMSNorm 对稳定性影响？
- 答：改善梯度流，降低深层训练难度。

19. 初始化不当会怎样？
- 答：早期梯度异常，模型难以进入有效训练状态。

20. 为什么要监控 logit 范围？
- 答：过大 logits 使 softmax 饱和，训练退化。

## 21-30：数据与批次策略

21. 有效 batch size 如何计算？
- 答：micro_batch × gradient_accumulation × data_parallel_world_size。

22. batch 变大后要调学习率吗？
- 答：常用线性缩放法则，但需配合 warmup 验证。

23. 为什么要做数据去重？
- 答：减少过拟合和记忆化，提高泛化。

24. 训练语料混合比例为什么重要？
- 答：决定模型能力分布，影响代码/数学/对话偏好。

25. curriculum learning 在 LLM 中有用吗？
- 答：有场景价值，但大规模预训练常用随机混合更简单稳健。

26. token 级损失掩码常见在哪？
- 答：SFT 中仅对 assistant 回复区间计算 loss。

27. packing（样本拼接）为什么能提速？
- 答：减少 padding 浪费，提高 token 利用率。

28. 动态长度 batch 的好处？
- 答：降低无效计算，提升吞吐。

29. 数据噪声对训练有何影响？
- 答：早期可带来正则化，过高噪声会拖慢收敛并降低上限。

30. 如何做小规模快速验证？
- 答：固定小数据子集 + 高频 eval，先验证趋势再放大全量训练。

## 31-40：优化效率

31. DDP 的核心同步点在哪？
- 答：反向传播期间 all-reduce 梯度。

32. ZeRO 的价值？
- 答：分片参数/梯度/优化器状态，降低单卡显存压力。

33. FSDP 与 DDP 区别？
- 答：FSDP 更强显存优化，工程复杂度更高。

34. 为什么通信会成为瓶颈？
- 答：模型越大，梯度同步量越大，网络带宽限制明显。

35. gradient accumulation 的代价？
- 答：吞吐下降、优化步变稀疏，但显存显著节省。

36. FlashAttention 对训练也有帮助吗？
- 答：有，减少 attention 访存，提升速度并节省显存。

37. fused optimizer 的意义？
- 答：减少 kernel launch 和内存访问，提升 step 效率。

38. 为什么要 profile 训练？
- 答：定位瓶颈（数据加载、通信、kernel），避免盲目调参。

39. dataloader 常见瓶颈？
- 答：CPU 解码慢、I/O 慢、worker 数不足。

40. 如何判断是“算力瓶颈”还是“I/O 瓶颈”？
- 答：GPU 利用率高且稳定多为算力瓶颈，GPU 空转且数据等待多为 I/O。

## 41-50：评估与调参实战

41. 训练中应该多久评估一次？
- 答：按 token/step 固定频率，兼顾反馈及时性与开销。

42. perplexity 降了但下游没提升，为什么？
- 答：任务分布不匹配，或模型学到的是语言流畅性而非任务能力。

43. 早停（early stopping）适合预训练吗？
- 答：不常用；预训练更看 scaling law 与预算，不是传统小数据监督学习。

44. SFT 常见过拟合信号？
- 答：训练 loss 继续下降，验证质量/人工偏好不升反降。

45. 正则化手段在 LLM 常见哪些？
- 答：weight decay、dropout（部分场景）、数据增强、混合语料。

46. 调参优先级建议？
- 答：先学习率和 warmup，再 batch 和序列长度，再优化器细参。

47. 为什么“先小跑通再放大”是铁律？
- 答：能快速发现管线错误，避免大规模烧卡成本。

48. 如何做训练故障恢复？
- 答：定期保存 checkpoint（模型+优化器+scheduler+随机状态）。

49. checkpoint 保存太频繁有什么问题？
- 答：I/O 开销大，影响吞吐并增加存储成本。

50. 一句话总结训练优化？
- 答：稳定性优先于极限速度，先保收敛再追吞吐。

## 面试加分模板

- 先说“现象”：例如 loss 抖动。
- 再说“定位”：学习率、梯度范数、数据批次统计。
- 最后说“动作”：调 LR/warmup、加裁剪、做小集回归验证。
